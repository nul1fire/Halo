# Security Policy

## Supported Versions / Поддерживаемые версии

We actively support the following versions of Halo with security updates:  
Мы активно поддерживаем следующие версии Halo обновлениями безопасности:

| Version / Версия | Supported / Поддержка    |
| ---------------- | ------------------------ |
| 1.0.x            | :white_check_mark:       |
| < 1.0            | :x:                      |

## Reporting a Vulnerability / Как сообщить об уязвимости

If you discover a security vulnerability within Halo, please open a private GitHub Security Advisory or contact the maintainer directly.  
Если вы обнаружили уязвимость в безопасности Halo, пожалуйста, откройте приватное обращение GitHub Security Advisory или свяжитесь с мейнтейнером напрямую.

- Do not open public GitHub Issues for security vulnerabilities.  
  Не создавайте публичные Issue для уязвимостей безопасности.
- Provide a detailed description and steps to reproduce the issue.  
  Предоставьте подробное описание и шаги для воспроизведения проблемы.

We will acknowledge your report as soon as possible and work on a fix.  
Мы подтвердим получение вашего отчета как можно скорее и займемся исправлением.
