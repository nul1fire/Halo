# 🛸 Halo — Dynamic Island для Windows

> **Внимание:** Это **Pre-Release** версия. Проект находится в активной разработке. Возможны баги, плавающая производительность и нехватка функций. 
> На данный момент приложение ориентировано на русскоязычных пользователей (СНГ), так как весь интерфейс и логика локализованы.

Прозрачный, плавный и минималистичный Dynamic Island для рабочего стола Windows. Приложение работает поверх всех окон, перехватывает системные события и отображает их в виде красивой анимированной "пилюли" в стиле Apple.

## ✨ Функционал (Текущий статус)

- **Перехват музыки (Windows SMTC):** Подхватывает треки из Spotify, Яндекс.Музыки, браузеров (Chrome/Edge) и других плееров, интегрированных с Windows.
- **Умный буфер обмена:** Реагирует на `Ctrl+C`, показывая превью скопированного текста.
- **Часы и Дата:** Отображение локального времени.
- **Кастомизация (Базовая):** Возможность переключения между режимами (Только музыка, Только часы, Цикл, Скрытый режим).
- **Перетаскивание:** Островок и меню настроек можно двигать мышкой в любое место экрана.
- **Click-Through:** Прозрачные зоны окна не блокируют рабочий стол и клики проходят насквозь.

## 🛠 Технологии

- **Electron** — создание прозрачного overlay-окна поверх системы.
- **Vite + React + TypeScript** — быстрый рендеринг UI.
- **Tailwind CSS** — стилизация.
- **Framer Motion** — "баттеровые" (плавные) анимации и переходы между состояниями (crossfade).
- **PowerShell (WinRT)** — чтение системных медиа-данных (SMTC) и обложек альбомов без тяжелых C++ аддонов.

## ⚠️ Известные проблемы (Pre-Release)

- Приложение не имеет иконки в трее (закрыть можно через меню настроек -> Выход).
- Иногда прогресс-бар музыки может дергаться (зависит от того, как плеер отдает данные в Windows).
- Нет автозапуска с системой.

## 🚀 Как запустить (Для разработчиков)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/твой_юзер/Halo.git
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```
4. Сборка .exe файла:
   ```bash
   npm run build
   ```
